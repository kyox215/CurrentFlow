电流脉动 0.9.0：看见整机功耗，也找到更多耗电线索

电流脉动是一款原生 Mac 菜单栏功耗监测工具。这次更新保留简洁的供电流向图，把更多信息放在需要时才展开的详情里。

这次更新了什么？
• CPU、GPU、内置屏背光：直接显示 W 数，快速了解分项功耗。
• 应用 CPU 耗电排行：在详情查看前三名，合并同一应用的辅助进程，帮助查找占用线索。
• 风扇转速：查看两只风扇实际 RPM。
• Wi-Fi 参考功耗：显示硬件提供的参考 W 数，明确标注读数范围。
• 按需采样：应用排行只在详情可见时每 2 秒更新，收起或关闭即暂停。

菜单栏继续只显示紧凑的整机 W 数。供电动画、近一分钟整机功耗趋势、自定义刷新、开机自启和静默启动继续保留。App 在本地运行，无账号、广告或遥测，不需要 root。

读数说明
CPU/GPU 和应用排行是系统能耗模型的区间平均估算；应用 CPU 功耗不等于整个 App 的总耗电。屏幕项仅包含内置屏背光。Wi-Fi 在本机传输测试中保持约 0.033 W，因此作为参考值显示，不承诺准确反映瞬时无线功耗。风扇显示转速，不换算虚构瓦数。缺失数据显示“—”。

支持 Apple Silicon（M 系列）和 macOS 13+，免费、MIT 开源。下载 DMG 或 ZIP 后，将“电流脉动.app”放入应用程序再打开。安装包使用 ad-hoc 签名，尚未进行 Apple Developer ID 公证；macOS 可能提示开发者未验证，亦可检查源码后自行构建。下载页和发行版提供 SHA256 校验和。

本版通过 229 项自动检查，并在 M5 Pro 上验证了原生详情展开、真实读数、收起后停止进程扫描和静默启动。不同机型或系统暴露的硬件计数器可能不同，无法读取的项目保留空值。
